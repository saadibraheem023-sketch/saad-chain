# Saad Chain - Simple Blockchain in Python

مشروع بلوكشين بسيط تم بناؤه باستخدام Python و Flask. يهدف إلى فهم أساسيات تقنية البلوكشين مثل التعدين (Mining)، إثبات العمل (Proof of Work)، والمعاملات (Transactions).

## ✨ المميزات
- إنشاء بلوك البداية (Genesis Block).
- تعدين بلوكات جديدة (Mining).
- إضافة معاملات (Transactions).
- التحقق من صحة السلسلة (Chain Validity).

## 🛠️ التقنيات المستخدمة
- Python
- Flask
- REST API
